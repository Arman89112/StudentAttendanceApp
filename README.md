# Student Attendance App (学生考勤管理系统)

A desktop application built with Java, JavaFX, SQLite, and Apache POI for managing student attendance, semesters, subjects, and generating reports (Excel/PDF).

## Features (功能特点)
- **Attendance Management:** Track daily/weekly student attendance.
- **Data Persistence:** Uses SQLite for storing student and attendance records.
- **Export & Import:** Excel and PDF export/import support using Apache POI and OpenPDF.
- **Modern UI:** Built with JavaFX and custom styling support (Dark/Light mode).

## Prerequisites (环境要求)
- JDK 21 or higher
- Maven 3.x

## Build & Run (构建与运行)
To run the application using Maven:
```bash
mvn javafx:run
```
